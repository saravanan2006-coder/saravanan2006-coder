### 🏪 Pocket சந்தை — B2B Wholesale Marketplace
> Tamil Nadu's digital marketplace bridging wholesalers & retailers across all 38 districts

- 🔐 Role-based auth (Wholesaler / Retailer) with UUID email verification
- 🏬 Seller dashboard — full stock CRUD, business profile management
- 🔍 Smart search with district + category filters, bookmarks & comparison table
- 🌐 Bilingual UI (Tamil + English), deployed on **Render.com** with **Gunicorn + WhiteNoise**
- 🗄️ PostgreSQL (prod) / SQLite (dev) with 5 relational models

### 🛒 E-Commerce Website — Thenmozhi Korai Mats
> Showcasing heritage handwoven korai mats from Tamil Nadu with a full order system

- 🛍️ Dynamic product grid with auto price calculation in vanilla JavaScript
- 📍 District/taluk-level delivery filtering (Villupuram, Cuddalore, Kallakurichi)
- 💬 WhatsApp contact integration — zero backend, fully static
- 📱 Fully responsive, zero-dependency frontend

### 🤖 ECprep — AI-Powered Study Assistant
> Reduce exam prep time with AI-generated summaries and quizzes from your own notes

- 📄 Upload any PDF — get instant topic-wise AI summaries
- 📝 Auto-generated MCQ-style practice questions for exam prep
- ⚡ Built with Python + Streamlit for a fast, clean UI
